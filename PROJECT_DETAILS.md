# 💰 SPENDWISE

# SMART STUDENT EXPENSE TRACKER WITH BUDGET ALERTS AND ANALYTICS

---

## 📌 PROJECT OVERVIEW

SpendWise is a smart web-based expense tracking application developed especially for students to manage daily expenses and maintain financial discipline. The application helps users record expenses, set monthly budgets, receive alerts when spending exceeds the budget limit, and analyze spending patterns using charts and reports.

The main purpose of this project is to improve money management habits among students through a simple and user-friendly system.

---

# ❗ PROBLEM STATEMENT

Many students struggle to manage their daily expenses and pocket money effectively. Traditional expense tracking methods such as notebooks or manual calculations are inefficient and time-consuming. Due to poor financial tracking, students often overspend and fail to maintain budgets.

SpendWise provides a digital solution that allows students to track expenses easily, maintain budgets, and analyze spending behavior efficiently.

---

# 🎯 OBJECTIVES

* To develop a simple expense tracking system for students
* To help users manage monthly budgets effectively
* To provide alerts when expenses exceed budget limits

# ✨ FEATURES

* Add, edit, and delete expense records
* Monthly budget management

---

# 🧩 MODULES

## 1. EXPENSE MANAGEMENT MODULE

This module allows users to add, update, and delete expense details such as amount, category, date, and description.

## 2. BUDGET MANAGEMENT MODULE

This module helps users set monthly budget limits and monitor total expenses.

## 3. ALERT SYSTEM MODULE

This module generates warning alerts with beep sound notifications whenever the spending exceeds the budget limit.

## 4. ANALYTICS MODULE

This module displays expense analysis through pie charts and bar charts for better understanding of spending patterns.

## 5. DATABASE MODULE

This module stores all user, expense, and budget information securely using MySQL database.
